# ЛИТАС Кроулер v0.1.0

Первая тестовая нативная Android-версия приложения управления рентгеновским кроулером.

## Реализовано

- Kotlin + Jetpack Compose.
- Главный экран оператора в стилистике ЛИТАС.
- Состояния кроулера.
- Телеметрия аккумуляторов.
- Датчики начала и конца трубы, воды и препятствия.
- Расстояние, крен, тангаж, торможение и RSSI.
- Ручное движение только во время удержания управляющего элемента.
- Автоматическое движение из состояния STOP.
- Отдельная крупная команда STOP.
- Mock-транспорт для разработки без оборудования.
- Native Android BLE-сканирование.
- Подготовка подключения с LE Coded PHY.
- Gradle Wrapper 8.11.1.
- CI-сборка APK.

## Ограничения версии

Это предварительная инженерная версия, а не готовый к эксплуатации пульт управления рентгеновской установкой.

Пока не подключены:
- окончательный BLE-протокол;
- реальные UUID;
- ACK / sequence / CRC;
- PIN и первичное сопряжение;
- экспозиция и её блокировки;
- сервисный режим;
- производственная подпись APK.

До завершения этих этапов версия предназначена только для разработки и проверки интерфейса.
