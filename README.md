# АЛИТАС — управление рентгеновским кроулером

Первая рабочая основа мобильного приложения по ТЗ версии 0.1 от 14.10.2026.

## Что уже есть

- React Native + Expo + TypeScript.
- Адаптивный главный экран оператора.
- Фирменная сине-белая стилистика по логотипу АЛИТАС.
- Модель пяти состояний кроулера.
- Телеметрия двух аккумуляторов, датчиков, углов, расстояния и BLE.
- Ручное движение только при удержании элемента управления.
- Команда STOP выделена как критическая.
- Mock-транспорт и симулятор телеметрии.
- Отдельный транспортный интерфейс для будущего реального BLE.

## Запуск

npm install
npm start

Для будущего реального BLE будет нужен development build (expo run:android), а не Expo Go.

## Архитектура

src/services/CrawlerTransport.ts — граница между UI и каналом связи.
src/services/MockCrawlerTransport.ts — симулятор.
src/hooks/useCrawlerController.ts — управление состоянием приложения и командами.
src/types/crawler.ts — типы домена.
src/theme/colors.ts — дизайн-токены АЛИТАС.

Важно: приложение не подменяет аппаратную и контроллерную логику безопасности.
